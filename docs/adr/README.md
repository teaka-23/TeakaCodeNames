# Architecture Decision Records

Короткие записи о решениях, которые влияют на контракты, деплой или границы фич.

## Правила

- Пишем ADR только на развилки (не на каждый PR).
- Формат: Context → Decision → Consequences.
- Статусы: `Proposed` | `Accepted` | `Superseded` | `Deprecated`.
- Имя файла: `NNNN-short-kebab-title.md`.
